Where should the cutoff be?

Every message has a score, and anything above the line is "important". Each sample message also has a human label. Move the line and watch the classic trade-off: catch everything (recall) vs. no false alarms (precision).

🙈 Missed (important but below the line)

🔔 False alarms (not important but above)

🔧 Why this matters: precision = of the messages flagged, how many really mattered. Recall = of the messages that mattered, how many got flagged. Missing a text from your landlord costs more than one extra promo, so the app's default cutoff (55) favors recall. Choosing a threshold from the cost of each kind of mistake is a core data-science decision.
